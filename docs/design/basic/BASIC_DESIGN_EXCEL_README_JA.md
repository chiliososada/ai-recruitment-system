# 基本設計書(Excel)について

本ディレクトリには、ケイスタンプ株式会社が作成した AI人材採用マッチングシステムの
日本語・Excel形式 基本設計書を格納する。

## 成果物

- `AI人材採用マッチングシステム_基本設計書.xlsx` — 基本設計書(23シート, 00_表紙〜21_証跡 + 99_用語集)。
- `EXCEL_DOCUMENT_VERIFICATION_JA.md` — 作成・検証記録(行数・コマンド・終了コード)。

## 再生成手順

ワークブックは生成スクリプトから再現可能に生成する。実装ソースには手を加えない。

```bash
# 依存(openpyxl)が無い場合のみ。
python3 -c "import openpyxl" 2>/dev/null || pip install --user openpyxl

python3 scripts/docs/build_basic_design_xlsx.py
# => docs/design/basic/AI人材採用マッチングシステム_基本設計書.xlsx を出力する
```

## 方針

- 文体は一貫して **である調** を用いる。
- 各行は画面/API/テーブル/項目/規則/トレース単位で記述し、巨大な段落シートを避ける。
- 証跡列に要求根拠・実装根拠(`apps/...`)・テスト根拠(`*.test.ts` 等)を示す。
- 実装にない挙動は記載せず、要求と実装の差異は明示分類(一致/要求のみ/実装のみ/部分実装/仕様差異/確認不能)する。

## 要求仕様の取扱い

要求仕様(FR-01〜FR-10)を要求範囲の基準とする。要求仕様書の細目とFR単位を超えた突合は要件担当との
確認事項として残し、確定後に反映する。詳細は `EXCEL_DOCUMENT_VERIFICATION_JA.md` §5 を参照。
